# AI/AX Learning Lab

AI 코딩 도구로 개발하는 방법과, 모델을 업무 앱에 연결하는 기술을 14주 동안 실습하는 학습 저장소입니다. 1-12주차에는 제공된 업무 요구를 AI와 함께 설계·구현하고, 13-14주차에는 원하는 포트폴리오를 구체화해 제작합니다. 그 코드·설정·실행 결과와 학습 노트를 이곳에 쌓습니다. Git, 기본 테스트, HTTP, JSON에 익숙한 개발자를 대상으로 합니다.

지금 학습 중인 주차는 [CURRENT_WEEK.md](CURRENT_WEEK.md)에서, 전체 본문은 [LEARNING_GUIDE.md](LEARNING_GUIDE.md)에서 볼 수 있습니다.

## 과정 구성

과정은 네 단계로 이어집니다.

| 단계 | 주차 | 배우는 것 |
|---|---|---|
| AI와 개발하는 방법 | 1-5 | 요구를 전달하고 결과를 판단하는 법, 반복 절차를 담는 Skill, 외부 기능을 연결하는 MCP, 작업 분리와 통합, 실행·검사·복구를 묶는 개발 하네스 |

## 학습 방식

한 주는 Day 1-5로 나뉘며, 각 실습은 **개념 이해 → 요구에서 구성 도출 → AI와 설계·구현 → 실행 결과 해석** 순서로 진행합니다.

- **교재**는 실제 코드·입출력으로 개념과 설계 이유를 설명합니다. 주차 README에 개념 설명, Day별 실습, 대화창에 보낼 요청문, 완료 기준이 있습니다.
- **AI**는 구성을 추천하고 구현합니다. 학습자는 추천의 이유와 예상 동작을 검토하고, 실행 결과와 대조합니다.
- **제작**은 공개할 기능의 입력·출력, 보관할 정보, 실행·종료 규칙을 요구에서 정하는 데서 시작합니다. 참고 코드는 선택의 근거를 읽는 자료이며 정답으로 고정되어 있지 않습니다.
- **1-12주차**는 제공된 업무와 자료로 진행합니다. **13-14주차**는 주제·기능·기술 스택·결과물 형태·배포 여부를 학습자가 정합니다.
- **언어**는 Java가 기본이며 빌드에는 Gradle Wrapper를 씁니다. LangChain·LangGraph를 비교하는 7주차와 Dify Tool Plugin을 만드는 9주차에는 Python을 씁니다. 12주차는 Java를 기본으로 통합 앱을 직접 구현하고, 필요한 라이브러리는 기능별로 선택한 뒤 LangChain4j 참고 구현과 비교합니다.
- **실행**은 IDE나 앱 화면을 먼저 씁니다. CLI는 자동화·프로세스 연결·반복 실행처럼 더 적합한 경우에 씁니다.

대역 모델로 통과한 검사와 실제 모델·Host에 연결해 확인한 결과는 구분해 기록합니다.
