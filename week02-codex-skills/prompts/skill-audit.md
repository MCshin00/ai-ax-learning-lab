# Skill 구조 검토

> 분류: **[검토 요청]** — 1차 판단 뒤 수동 전송

## 사용 방법

`week02-codex-skills/lab/`를 Codex 앱의 primary folder 또는 CLI의 CWD로 둡니다. Skill은 이 폴더의 `.agents/skills/` 아래에 있습니다. 먼저 비교할 Skill 두 개의 `SKILL.md`, 참조 자료와 스크립트를 직접 읽고 차이를 간단히 적습니다. 아래 본문의 두 경로를 채운 뒤 새 대화창에 직접 붙여넣어 보냅니다. AI의 표는 본인이 놓친 부분을 찾는 데 사용하고, 최종 판단은 원문을 다시 확인해 내립니다.

## 전송할 본문

```text
다음 두 Skill의 구조를 읽기 전용으로 비교해 주세요.

- Skill A: {SKILL_A_PATH_OR_NAME}
- Skill B: {SKILL_B_PATH_OR_NAME}

코드와 문서는 수정하지 말고, 각 Skill을 다음 열이 있는 표로 정리해 주세요.

- 이름과 해결하는 작업
- description의 범위
- 발동해야 하는 요청과 발동하면 안 되는 요청
- 실행 절차
- 참고 문서·스크립트·템플릿의 역할
- 모델이 판단하는 부분
- 코드가 결정적으로 검사하는 부분
- 필요한 입력과 남기는 결과

description이 지나치게 넓거나 좁아 보이는 부분, 모델 판단을 결정적 검사로 옮길 수 있는 부분은 근거 경로와 함께 표 아래에 적어 주세요. 원문에서 확인할 수 없는 내용은 추정하지 말고 NOT_VERIFIED로 표시해 주세요.
```

## 전송 후 확인

- AI가 인용한 경로와 설명이 실제 파일과 맞는가
- 발동 범위에 대한 반례가 빠지지 않았는가
- 모델과 스크립트의 책임을 잘못 바꾸지 않았는가
