# 실행한 Skill의 결과와 지침 연결하기

Skill을 한 번 사용한 뒤 `week02-codex-skills/lab/`에서 아래 요청을 직접 보냅니다. 혼자 분석표를 먼저 제출할 필요는 없습니다.

```text
방금 사용한 Skill의 SKILL.md와 결과를 함께 설명해 주세요.
어떤 지침이 결과의 어떤 부분에 영향을 줬는지 두 곳만 짚어 주세요.
지침, 재사용 템플릿이 있다면 그 형식, 이번 출력 내용을 구분해 주세요.
틀린 부분은 구체적인 예와 수정안을 보여 주세요. 아직 파일을 고치지는 마세요.
```

가리킨 문장을 실제 파일에서 읽고 결과가 맞는지 판단합니다.
