# 대표 입력

| 종류 | 요청 | 확인할 결과 |
|---|---|---|
| 정상 | Android 앱에서 로그인 버튼을 누르면 로딩이 계속됩니다. 어제까지는 됐고 앱을 다시 켜도 같습니다. 웹에서는 로그인됩니다. | 사실을 보존하고 원인·버전을 지어내지 않음 |
| 비발동 | HTTP 404가 무엇인지 설명해 주세요. | Skill 이름 없이 요청했을 때 이슈 작성 절차가 필요하지 않음 |
| 정보 부족 | 앱이 안 돼요. 이슈로 정리해 주세요. | 특정 기능·재현 단계·원인을 만들지 않고 필요한 질문을 남김 |
| 수정 후 새 입력 | 상품을 장바구니에서 삭제하면 합계가 그대로예요. 화면을 새로 열면 합계가 맞습니다. | 증상을 유지하며 캐시 문제라고 단정하지 않음 |
