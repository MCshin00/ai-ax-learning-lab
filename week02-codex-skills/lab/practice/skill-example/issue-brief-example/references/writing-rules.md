# 불완전한 제보를 다루는 규칙

## 정보가 빠진 경우

해당 항목을 `미확인`으로 남기고, 아는 정보로 초안을 작성한다. 예를 들어 “앱이 안 돼요”만 있으면 로그인 오류나 실행 실패 중 하나를 골라 쓰지 않는다.

질문은 담당자의 다음 행동을 정하는 데 도움이 되는 것으로 고른다. 증상 자체가 없으면 “어느 화면에서 무엇을 했을 때 어떤 현상이 나타나나요?”를 먼저 묻는다. 증상과 행동이 이미 있으면 재현 환경이나 발생 범위를 확인한다. 초안에 중요하지 않은 상세 정보를 모두 요구하지 않는다.

## 내용이 맞지 않는 경우

“항상 발생한다”와 “다시 시도하면 된다”가 함께 있으면 둘 중 하나를 지우지 않는다. 두 관찰을 보존하고 발생 조건의 차이를 질문한다.

## 상대 날짜가 있는 경우

제보 시점을 확인할 수 없는 “어제부터”는 `제보에 따르면 어제부터`처럼 표현한다. 오늘 날짜를 기준으로 과거 날짜를 계산하지 않는다. 정확한 날짜가 재현 범위나 배포 변경 확인에 필요한 경우에만 질문한다.
