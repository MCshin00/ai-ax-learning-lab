# M5 실행 맥락

이 요청은 사용자가 수용한 구성에 따라 5주차 자체 하네스의 실제 진입점에서 전달한다. 작업 위치는 runs/M5이며 지원 요청 표시 구현은 src/main/java/lab/week10/의 세 파일에 적용한다.

## 수용한 책임과 반환 계약

- Priority.normalize는 우선순위 별칭·대소문자·앞뒤 공백을 정리하고 없는 값과 알 수 없는 값은 P1로 반환한다.
- Title.normalize는 없는 제목을 빈 문자열로 반환하고 README의 공백 범위를 한 칸으로 정리한다.
- Summary.render는 정리한 제목이 비어 있으면 확인 필요만 반환한다. 제목이 있으면 정리한 우선순위와 제목을 조합한다. 실제 제목이 확인 필요인 경우에는 일반 제목으로 표시한다.

이 판단은 이미 수용되었으므로 같은 설계를 다시 묻지 않고 구현한다. 추가 판단이 필요한 정보·권한·실행 조건 부족은 최종 응답에 근거와 함께 알린다.

## 검사와 실행 경계

기존 검사 코드와 기대값, README 요구, 빌드·하네스 설정은 변경하지 않는다. 모델 응답 후 하네스가 test와 acceptance를 새로 실행해 완료를 판단한다. 업무 실패 근거가 전달된 복구 요청은 필요한 코드 수정 한 번에 해당한다. 하위 하네스나 별도 에이전트를 추가로 시작하지 않는다.

Windows PowerShell의 검사는 .\gradlew.bat --no-daemon --continue test acceptance, macOS·Linux·WSL은 ./gradlew --no-daemon --continue test acceptance다. 모델 내부에서 확인한 결과는 하네스의 독립 검사와 구분해 응답한다.

M5의 기존 프로젝트 로컬 소켓 설정과 JAVA_TOOL_OPTIONS를 유지한다. 환경변수 파일, 인증 파일, 키를 저장한 비공유 설정을 읽거나 환경변수 전체를 출력하지 않는다. 소켓 설정의 적용 확인은 해당 옵션의 존재와 실행 결과만으로 한다. 다른 프로젝트의 코드·학습 기록을 수정하지 않는다. 학습 근거는 상위 작업에서 기존 주차 노트에 이어 기록한다.
