# v2 실행 설정 연결 확인

이번 실행은 Day 5에서 수용한 실행 설정 전달·기록의 검증이다. 같은 지원 요청 과제의 완료된 코드를 사용하며 기존 M5 비교 실행의 결과를 대체하지 않는다.

기존 구현과 공통 요구를 대조하고, 이미 충족하면 코드를 다시 작성하거나 정리하지 않는다. 하네스가 응답 뒤 test와 acceptance를 실제로 실행한다. 요구 불일치가 있다면 구체적인 입력·기대값·코드 위치를 보고한다. 독립 검사 실패의 복구 요청이 전달되었을 때만 필요한 수정을 한다.

최종 응답은 확인한 동작과 변경 여부를 짧게 적는다. 모델이 자신의 이름이나 추론 단계를 답하는 문장을 실행 설정의 적용 증거로 사용하지 않는다.
