# M5에 사용할 공통 작업

5주차에서 설계·구현한 하네스 v1의 실제 진입점을 사용합니다. 실행 파일명·작업 형식·상태 이름·설정 구조를 이 문서의 특정 클래스에 맞출 필요는 없습니다.

| 공통 비교 조건 | 내 엔진에서 연결할 내용 |
|---|---|
| 작업 대상 | `runs/M5/`의 같은 시작 코드 |
| 요구 | `m5-task.md`와 M5 복사본의 `README.md` |
| 완료 근거 | M5 폴더에서 기존 `test`와 공개 수용 `acceptance` 실제 실행 |
| 재시도 범위 | 업무 검사 실패에 필요한 수정 후 최대 한 번 복구·재검사 |
| 정보·실행 조건 부족 | 필요한 내용을 알리고 사람의 판단을 받거나 중단 |
| 남길 결과 | 첫 실행과 복구 여부, 외부 검사 결과, 최종 상태와 필요한 사람 개입 |

5주차 엔진의 실제 작업 입력을 AI와 읽고 위 내용을 어디에 표현해야 하는지 정합니다. 예를 들어 명령행 인자로 요청 파일과 작업 폴더를 받는 엔진이면 그 인자를 사용하고, 작업 객체를 읽는 엔진이면 자신의 필드에 대응시킵니다. 이미 선택한 구조를 유지하며 의미가 다른 필드에 억지로 끼워 넣지 않습니다.

검사 명령은 M5 작업 폴더에서 Windows PowerShell `.\gradlew.bat test acceptance`, macOS·Linux·WSL `./gradlew test acceptance`입니다. 엔진이 프로세스를 호출할 때는 사용 중인 실행 보조 코드에 맞는 명령 배열을 사용합니다.

준비된 실제 명령 한 개를 주차 노트에 남기고 실행합니다. 특정 `Harness` 클래스나 배포된 고정 JSON을 채우는 방식으로 대체하지 않습니다. 참고 엔진을 선택한 경우에도 그 구조를 내 요구에서 선택한 이유와 실제 수정·연결을 설명합니다. 비교 예제의 정상 실행만으로 자신의 엔진 제작을 완료했다고 판단하지 않습니다.
