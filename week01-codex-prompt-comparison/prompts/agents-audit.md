# [검토 요청] `AGENTS.md` 적용 확인

## 사용 방법

작업 결과를 확인한 뒤 현재 작업 폴더에서 아래 본문을 직접 보냅니다. 요청·README·반복 규칙의 역할을 실제 변경에 연결하는 활동입니다.

## 직접 보낼 내용

```text
현재 작업에 적용되는 AGENTS.md와 이번 요청·README를 읽기 전용으로 살펴봐 주세요.
각 문서의 역할과 적용 범위를 실제 파일 위치로 설명해 주세요.
이번 변경의 요구가 어떤 코드와 테스트에 반영됐는지 연결해 주세요.
어떤 내용은 반복 규칙으로 두고 어떤 내용은 이번 요청에 남기는지 이유를 설명해 주세요.
자료에 적힌 이유와 현재 구조에서 추론한 효과를 구분해 주세요.
충돌하거나 모호한 규칙이 있으면 문구를 짚고 고칠 후보와 예상 영향을 알려 주세요. 아직 수정하지 마세요.
```

응답을 실제 파일·diff와 대조하고 반복 규칙을 바꿀 필요가 있는지 판단합니다. 새 지침 계층이나 분석 보고서를 만들 필요는 없습니다.
