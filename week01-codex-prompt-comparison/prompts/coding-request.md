# 작은 작업을 요청하고 확인하기

`week01-codex-prompt-comparison/lab/ticket-title-normalizer/`를 Codex 작업 폴더로 엽니다.

```text
README의 요구사항대로 제목 정규화를 구현해 주세요.
기존 테스트를 삭제하거나 약화하지 말고 실행해서 결과를 알려 주세요.
내가 확인할 핵심 변경과 아직 확인하지 못한 사항을 설명해 주세요.
```

실행 후 구조와 예상 결과를 확인합니다.

```text
README의 요구가 구현과 테스트에 어떻게 연결됐는지 실제 위치를 보여 주세요.
입력이 검사·변환·반환되는 경로와 각 부분을 나눈 효과를 설명해 주세요.
다른 입력의 결과를 예상해 볼 수 있게 도와주세요. 아직 수정하지 마세요.
```

직접 위치를 확인한 뒤 문제가 있거나 필요한 작은 변경이 있으면 다음 요청을 보냅니다.

```text
이 입력에서 기대한 결과는 [기대], 실제 결과는 [관찰]입니다.
바꿀 위치와 수정 후 예상 동작을 설명하고 필요한 변경을 적용해 주세요.
같은 입력과 관련 테스트를 다시 확인하고 예상과 실제 결과를 대조해 주세요.
```
