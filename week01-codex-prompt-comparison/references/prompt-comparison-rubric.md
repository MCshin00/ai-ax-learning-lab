# 프롬프트 비교 원시 증거표

Run A와 Run B를 임의의 합산 점수로 환산하지 않습니다. 같은 관찰 단위와 아래 원시 증거를 나란히 기록합니다.

| 관찰 항목 | Run A | Run B | 기록 규칙 |
|---|---|---|---|
| 공개 테스트 |  |  | 통과 수, 실패 수, 실행 명령 |
| 인수 조건 |  |  | 충족·실패·`NOT_VERIFIED` 수와 해당 조건 |
| 금지 조건 |  |  | 위반 수와 실제 변경 경로 |
| 완료 보고 |  |  | 변경 파일·테스트·남은 위험의 포함 여부 |
| 사람 개입 |  |  | 추가 지시 횟수와 지시 내용 |
| 소요 시간 |  |  | 같은 시작·종료 규칙으로 잰 관찰값 또는 `NOT_AVAILABLE` |

원시 로그, 테스트 출력, diff를 먼저 보존하고 해석은 별도 문단에 씁니다. 실행하지 않았거나 확인할 수 없는 항목을 성공으로 간주하지 않습니다.
