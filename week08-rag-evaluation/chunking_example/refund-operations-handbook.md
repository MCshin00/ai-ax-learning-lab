# 결제·환불 운영 안내서

상담원이 환불과 보상 요청을 접수할 때 따르는 기준이다. 요청 유형마다 대상, 접수 기한, 확인 절차, 예외, 승인 기준이 다르므로 해당 유형의 절을 끝까지 확인한다.

## 이중 결제 환불

### 대상

같은 주문에 동일한 금액이 두 번 이상 승인된 경우를 말한다. 결제 수단이 서로 달라도 주문 번호와 금액이 같으면 대상에 포함한다.

### 접수 기한

접수 기간은 결제일로부터 30일이다. 마지막 승인 건의 결제일을 기준으로 계산하며, 기한이 주말이나 공휴일에 끝나면 다음 영업일까지 접수한다.

### 확인 절차

상담원은 결제 식별자 두 건을 모두 조회하고 요청자가 결제 계정의 소유자인지 확인한다. 두 건의 승인 시각과 금액을 상담 기록에 남긴 뒤 환불 초안을 작성한다.

### 예외

다음 경우에는 접수하지 않고 결제 담당자에게 이관한다. 결제 계정의 소유권을 확인하지 못한 경우, 카드사에 이의 제기가 이미 접수된 경우, 두 승인 중 한 건이 이미 취소된 경우가 여기에 해당한다.

### 승인

환불 금액이 10만 원 이상이면 팀장 승인이 필요하다. 그보다 적은 금액은 상담원이 작성한 초안을 다른 상담원이 검토한 뒤 실행한다.

## 구독 해지 환불

### 대상

정기 구독을 해지한 고객이 남은 이용 기간의 요금을 돌려받으려는 경우를 말한다. 월간 구독과 연간 구독 모두 대상이다.

### 접수 기한

접수 기간은 해지일로부터 14일이다. 해지 예약만 하고 이용 기간이 남아 있는 상태에서는 접수하지 않으며, 실제 해지일 이후에 접수한다.

### 계산 방식

남은 이용 일수를 일 단위로 계산한다. 연간 구독은 사용한 달에 월간 요금을 적용해 다시 계산한 뒤 차액을 돌려준다.

### 예외

다음 경우에는 환불 대상에서 제외한다. 할인 행사로 가입한 첫 결제 기간, 이용 기간 중 추가 저장 용량을 구매해 사용한 금액, 약관 위반으로 이용이 정지된 계정이 여기에 해당한다.

### 승인

연간 구독의 환불은 금액과 관계없이 팀장 승인이 필요하다. 월간 구독은 상담원이 계산 결과를 기록한 뒤 실행한다.

## 서비스 장애 보상

### 대상

공지된 장애로 서비스를 연속 2시간 이상 이용하지 못한 유료 고객을 말한다. 무료 체험 중인 계정은 대상이 아니다.

### 접수 기한

접수 기간은 장애 종료 공지일로부터 60일이다. 공지가 여러 번 수정됐다면 마지막 종료 공지일을 기준으로 한다.

### 보상 방식

현금으로 지급하지 않고 다음 결제에 사용할 수 있는 이용권으로 지급한다. 이용권의 금액은 장애 시간에 해당하는 일일 요금의 세 배다.

### 예외

다음 경우에는 보상하지 않는다. 일주일 전에 공지한 정기 점검, 고객의 네트워크나 기기 문제로 접속하지 못한 경우, 장애 시간이 연속 2시간에 미치지 못한 경우가 여기에 해당한다.

### 승인

이용권 지급은 장애 공지 번호를 확인한 상담원이 바로 실행한다. 같은 장애에 대해 두 번 지급하지 않도록 지급 기록을 먼저 조회한다.

## 미제공 서비스 환불

### 대상

결제한 부가 서비스가 약속한 날짜까지 제공되지 않은 경우를 말한다. 설치 지원, 데이터 이전, 교육 일정처럼 날짜를 정해 제공하는 서비스가 대상이다.

### 접수 기한

접수 기간은 약속한 제공일로부터 45일이다. 제공일을 고객과 다시 정했다면 새로 정한 날짜를 기준으로 한다.

### 확인 절차

상담원은 계약서의 제공일과 작업 기록을 대조한다. 일부만 제공된 경우에는 제공된 항목과 제공되지 않은 항목을 나누어 기록한다.

### 예외

다음 경우에는 환불하지 않고 일정을 다시 잡는다. 고객이 필요한 자료를 전달하지 않아 작업을 시작하지 못한 경우, 고객이 일정 변경을 요청한 경우가 여기에 해당한다.

### 승인

일부 환불은 서비스 담당자의 확인이 필요하다. 전액 환불은 팀장 승인을 받은 뒤 실행한다.

## 공통 규칙

### 중복 실행 방지

환불과 보상은 요청마다 고유한 실행 키를 사용한다. 같은 키로 다시 요청하면 이전 실행 결과를 돌려주고 금액을 두 번 지급하지 않는다.

### 기록

모든 요청은 접수 시각, 확인한 사실, 적용한 절의 이름, 승인자를 상담 기록에 남긴다. 접수하지 않은 요청도 사유와 이관한 담당자를 기록한다.
