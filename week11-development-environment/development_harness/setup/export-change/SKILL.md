docs/project.md에서 현재 입력부터 출력까지의 경로를 읽는다.
개발 MCP의 get_acceptance_case로 해당 요구의 사례를 가져온다. 연결되지 않았다면 data/acceptance-cases.json의 같은 사례를 읽는다.
예시 입력과 현재 출력이 다른 위치를 찾고 필터·셀 표현·조합 중 어느 책임을 바꿀지 추천한다. 학습자의 의견을 반영한다.
요구를 확인하는 acceptance 검사를 추가하고 실제 기능을 변경한다. 구현과 같은 문자열을 복사한 기대값 대신 원문과 업무 조건에서 기대 결과를 정한다.
검사 결과에서 바뀐 행동을 설명하고 검토할 diff와 남은 판단을 제공한다.
