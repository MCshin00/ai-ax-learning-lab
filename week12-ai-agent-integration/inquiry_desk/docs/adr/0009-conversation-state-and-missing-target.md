# 0009 — 대화 상태와 서비스를 말하지 않은 문의

- 정한 날: 2026-10-09

## 상황

"접속이 안 돼요" 뒤에 "VPN이고 인증서 만료 메시지가 나와요"가 오면 같은 문의로 이어 처리해야 하고, 그 뒤의 "인증서 만료 메시지가 나와요"도 VPN 문의다. 같은 발언이 다른 대화에 오면 대상을 알 수 없다. 모델 API는 이전 대화를 기억하지 않으므로 앱이 무엇을 보관하고 무엇을 다시 보낼지 정해야 한다.

## 결정

| 정할 것 | 결정 |
|---|---|
| 대화의 구분 | 호출하는 쪽이 넘기는 대화 ID. 처음 보는 ID는 새 대화다 |
| 보관하는 것 | 대화마다 현재 접수 결과와 직원의 발언 원문. 프로그램의 메모리에 둔다 |
| 모델에 보내는 것 | 이전 접수 결과와 새 발언. 이전 발언의 원문은 보내지 않는다 |
| 합치는 쪽 | 모델이 이전 결과에 새 발언을 반영한 전체 결과를 돌려준다. 코드는 그 결과를 선언한 타입으로 읽고 같은 서비스를 하나로 합친다 |
| 서비스가 하나도 없을 때 | 코드에 정해 둔 질문을 돌려주고 조회하지 않는다 |
| 서비스가 모두 자료에 없을 때 (2026-10-10 추가) | 조회 결과와 함께 질문을 돌려준다. 결과 구분은 `NEEDS_INPUT`이고 `statuses`를 함께 담는다. 문장은 자료에서 찾지 못했다는 것, 제공하는 서비스 가운데 해당하는 것이 있으면 알려 달라는 것, 다른 시스템이면 이 도구로는 상태를 확인할 수 없다는 것을 말한다. 접수 결과는 대화 상태에 그대로 남긴다 |
| 접수에 실패했을 때 | 그 발언을 대화 상태에 반영하지 않는다 |

## 이유

이전 결과만 보내면 모델 입력이 작고, 앞에서 정해진 값이 매번의 재해석으로 흔들리지 않는다. 발언 원문을 보관하는 것은 담당자가 초안을 검토할 때 직원이 실제로 한 말을 볼 수 있어야 하고, 발생 시각처럼 접수 결과의 필드에 담기지 않는 내용이 남아야 하기 때문이다.

"통합 로그인도 느려요"는 서비스를 더하는 발언이고 "VPN이 아니라 통합 로그인 문제예요"는 바꾸는 발언이다. 이 구별은 문장을 이해해야 하는 일이어서 모델이 합친다.

짐작한 서비스로 진행하면 틀린 대상의 상태와 문서로 초안까지 만들 수 있다. 질문은 발언을 한 번 더 요구하지만 틀린 대상으로 진행하지 않는다. 질문 문장을 코드에 두면 항상 같은 질문이 나가고 검사에서 글자 그대로 비교할 수 있다.

실패한 발언을 반영하지 않으면 직원이 같은 발언을 다시 보낼 수 있다.

서비스가 모두 자료에 없을 때도 질문하는 것은 실제 모델의 결과가 갈렸기 때문이다. 같은 문장 "사내망 연결이 자꾸 끊겨요"를 세 번 실행하자 두 번은 서비스를 `사내망`으로 적어 `NOT_FOUND`만 나왔고 한 번은 서비스 없이 질문이 나왔다. 지침으로 가른 구분([0010](0010-intake-instructions-and-service-scope.md))이 안정적으로 지켜지지 않으므로, 모델이 어느 쪽으로 적든 진행할 대상이 없으면 직원이 다음에 할 말을 알 수 있게 코드가 질문을 돌려준다. 질문 문장을 나눈 것은 "급여 시스템"처럼 실제로 있는 다른 시스템을 말한 직원에게 제공하는 서비스 가운데 하나로 고치라고 요구하지 않기 위해서다. `NOT_FOUND`는 조회 자료에 없다는 뜻이고 그 시스템이 없다는 뜻이 아니다. 일부만 자료에 없으면 찾은 서비스로 진행하고, 상태 조회가 실패한 서비스는 있는지 없는지를 알 수 없으므로 이 경우에 넣지 않는다.

## 다시 볼 조건

- 모델이 합치다가 앞의 값을 빠뜨리는 것이 실제 실행에서 보이면 최근 발언의 원문을 함께 보내거나 코드가 합치는 방식을 검토한다.
- 직원들이 VPN을 "사내망"처럼 다른 이름으로 부르는 것이 확인되면 대응표에 그 이름을 더한다([0008](0008-intake-result-and-service-existence.md)).
- 질문이 서비스 말고 다른 것도 물어야 하면 모델이 질문을 쓰게 한다.
- 자료에 없는 이름을 말한 뒤의 발언("VPN이요")에서 모델이 앞의 이름을 지우지 않고 더하는 일이 보이면, 질문했다는 사실을 다음 호출에 함께 보내는 방식을 검토한다.
- 프로그램을 다시 시작한 뒤에도 대화를 이어야 하면 보관 위치를 바꾼다.
