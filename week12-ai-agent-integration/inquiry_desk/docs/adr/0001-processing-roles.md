# 0001 — 문의 처리의 순서와 맡는 쪽

- 정한 날: 2026-10-07

## 상황

직원의 자유로운 문의를 서비스 상태·운영 문서와 연결해 담당자가 검토할 작업 요청으로 만든다. 한 건을 처리하려면 문장 읽기, 상태 확인, 문서 찾기, 문장 쓰기, 고쳐서 전달하기가 필요하다.

## 결정

접수(모델) → 상태 조회(코드) → 운영 문서 검색 → 초안(모델) → 출처 검사(코드) → 검토·저장(담당자 확인 뒤 코드) 순서로 처리한다. 검색은 코드가 호출한다([0012](0012-runbook-search.md)).

## 이유

입력과 결과가 정해진 일은 코드로 쓸 수 있고, 자유로운 표현의 해석과 문장 작성은 그렇지 않다. 상태 조회와 저장은 건너뛰면 확인되지 않은 내용이 사실로 나가거나 검토하지 않은 요청이 전달되므로 코드가 순서를 정한다.

## 다시 볼 조건

문의를 서비스 선택창과 오류 코드로 받을 수 있게 되면 접수에 모델이 필요 없다.
