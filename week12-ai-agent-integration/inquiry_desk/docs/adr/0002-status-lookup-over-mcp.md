# 0002 — 서비스 상태 조회는 MCP 도구로 공개하고 코드가 호출한다

- 정한 날: 2026-10-07

## 상황

문의 앱과 운영팀 도구가 같은 조회를 써야 한다. 조회 대상은 접수가 끝나면 서비스 ID로 정해진다.

## 결정

조회를 문의 앱과 별도의 프로세스인 MCP 서버의 도구로 공개한다. 호출은 모델이 아니라 앱 코드가 정한다.

## 이유

두 프로그램이 같은 기능을 쓰려면 한 프로그램 안의 함수 호출로는 부족하다. 서비스 ID가 정해지면 모든 대상의 상태가 필요해서 모델이 고를 것이 없다. 모델에 맡기면 조회를 건너뛰고 답할 수 있다.

## 다시 볼 조건

기존 업무 API가 있는 조직이라면 MCP 서버가 그 API를 부르게 연결한다.
