# 0013 — 초안의 출처는 코드가 대조하고, 근거가 없으면 한 번 다시 찾는다

- 정한 날: 2026-10-10

## 상황

모델이 쓴 초안은 운영 문서를 근거로 해야 한다. 검색은 문서를 찾지 못할 수 있고([0012](0012-runbook-search.md)), 문서를 읽지 못해 실패할 수도 있다. 모델은 넘겨받지 않은 문서를 출처로 적을 수 있고, 호출이 실패하거나 응답이 잘릴 수 있다. 일부만 확인되어도 확인된 내용은 전달해야 한다.

## 결정

| 정할 것 | 결정 |
|---|---|
| 초안을 만드는 때 | 찾은 문서가 하나라도 있을 때만 모델을 호출한다. 입력은 접수 결과, 상태 조회 결과, 찾은 문서다 |
| 출처 검사 | 초안이 돌려준 출처가 비어 있지 않고 모두 이번에 찾은 문서의 ID인지 코드가 대조한다. 어긋나면 초안을 버리고 다시 호출하지 않는다 |
| 다시 찾기 | 문서가 있는 서비스에서 근거가 0개일 때만 모델이 검색어를 한 번 다시 쓴다. 다시 쓴 검색어로 근거가 0개인 서비스만 다시 찾는다 |
| 다시 쓴 검색어의 쓰임 | 검색에만 쓴다. 초안에는 원래 접수 결과를 준다 |
| 끝내 근거가 없을 때 | 확인한 상태와 찾은 근거는 돌려주고, 그 서비스에 `NO_EVIDENCE`를 남긴다 |
| 검색이 실패했을 때 | 검색어를 다시 쓰지 않는다. 그 서비스에 `SEARCH_FAILED`를 남긴다 |
| 접수 뒤의 모델 호출이 실패했을 때 | 거기서 멈춘다. 초안은 없고 그때까지의 상태와 근거를 돌려준다. 호출 실패는 `MODEL_UNAVAILABLE`, 쓸 수 없는 응답은 `INVALID_OUTPUT`이다 |
| 발언마다 | 접수에 성공한 발언마다 검색과 초안을 새로 한다. 앞선 발언의 초안을 대신 돌려주지 않는다 |
| 최상위 결과 | `READY` 그대로다. 초안이 있는지는 `draft`, 없는 이유는 `notices`로 본다 |

## 이유

출처의 대조는 값이 목록에 있는지를 보는 일이라 코드가 할 수 있고, 모델이 쓴 것을 모델이 가진 것과 다른 기준(코드가 가진 검색 결과)으로 확인한다. 어긋난 초안을 버리고 다시 호출하지 않는 것은, 근거는 있는데 출처가 어긋난 원인이 검색이 아니어서 같은 입력으로 다시 불러도 나아진다는 근거가 없기 때문이다.

근거의 유무로만 다시 찾는 것은 그 판정을 코드가 할 수 있어서다. 근거의 내용이 증상에 맞는지를 모델에게 평가시키면 호출이 늘고 평가의 오판이 새로 생긴다.

근거 없음과 검색 실패를 나누는 것은 담당자의 다음 행동이 다르기 때문이다. 앞의 경우는 문서를 보충하거나 직접 대응 방법을 정하고, 뒤의 경우는 검색 장애를 먼저 본다. 검색 실패에 검색어를 바꾸지 않는 것은 바꿔도 해결되지 않아서다. 문서가 하나도 없는 서비스도 같은 이유로 다시 쓰지 않는다.

모델 호출이 실패하면 멈추는 것은 규칙을 하나로 두기 위해서다. 다른 서비스의 근거로 초안을 이어 만드는 선택도 있지만, 실패한 단계마다 이어 갈 범위를 따로 정해야 한다. 상태와 근거는 이미 확인된 것이므로 돌려준다.

`READY`를 그대로 두는 것은 "검토 필요" 같은 값이 저장 전의 담당자 검토와 같은 말로 두 뜻이 되기 때문이다. `READY`는 접수가 성립했다는 뜻이고, 초안이 있다거나 저장해도 된다는 뜻이 아니다.

## 알고 있는 한계

- 출처 검사는 출처가 있고 이번 검색 결과에 들어 있는지만 확인한다. 본문의 문장이 그 문서를 근거로 썼는지, 서비스별 설명과 문서가 맞게 짝지어졌는지, 문서에 없는 처리 완료를 썼는지는 확인하지 못한다. 담당자의 원문 대조가 맡는다.
- 다시 쓴 검색어가 실제로 문서의 용어에 가까워지는지는 자동 검사로 확인하지 못한다. 실제 모델로 실행해 본다.

## 다시 볼 조건

- 출처는 맞는데 원문에 없는 내용을 쓴 초안이 실제 실행에서 나오면 초안 지침을 고치고, 그래도 남으면 문장 단위의 출처를 받는 방식을 검토한다.
- 여러 서비스의 초안에서 설명과 문서가 뒤바뀌는 일이 나오면 서비스마다 초안과 출처를 나눠 받는다.
- 한 번의 다시 찾기로 부족한 사례가 쌓이면 횟수보다 검색 방식을 먼저 본다([0012](0012-runbook-search.md)).
- 다시 쓰기만 실패하고 다른 서비스의 근거는 충분한 경우가 실제로 잦으면 찾은 근거로 초안을 이어 만드는 쪽을 검토한다.
