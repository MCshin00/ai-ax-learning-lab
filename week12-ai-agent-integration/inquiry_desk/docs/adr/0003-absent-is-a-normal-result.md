# 0003 — 자료에 없는 것은 정상 응답, 하지 못한 것은 원인 값과 함께 오류

- 정한 날: 2026-10-07

## 상황

도구의 결과는 세 가지로 갈린다. 찾는 것이 있다, 자료에 없다, 조회 자체를 하지 못했다. "VPN과 급여 시스템이 안 돼요"처럼 여러 대상을 차례로 조회할 때 이 셋이 구별되어야 한다.

## 결정

자료에 없는 것은 정상 응답 안의 "없음"으로 돌려준다. 하지 못한 것은 오류로 알리되 원인을 구별하는 값을 응답에 직접 넣는다. 조회 도구 하나가 아니라 이 앱이 공개하는 모든 도구에 적용한다.

## 이유

자료에 없는 것은 호출이 실패한 것이 아니라 값이 없는 것이다. MCP의 도구 오류에는 HTTP 상태 코드 같은 표준 구분 값이 없어서, 오류로 알릴 때는 구분 값을 직접 넣어야 한다. 안내 문구를 해석해야만 구별되는 형태는 문구가 바뀌면 깨진다.

## 다시 볼 조건

없는 대상을 조회하는 것 자체가 호출한 쪽의 잘못인 업무라면 오류로 알리는 쪽이 맞다.
